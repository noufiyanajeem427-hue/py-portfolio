Individual Projects

  • MindForge – Online Collaboration Tool

    MindForge is a web-based collaboration platform designed to help teams work together efficiently in real time. The application provides a centralized workspace where users can collaborate on projects from anywhere.

    It includes shared workspaces that allow team members to organize projects, manage tasks, assign responsibilities, and monitor progress through a single platform. The platform also offers real-time chat and document collaboration features, enabling seamless communication without switching between different applications.

    By integrating project management, communication, and collaboration tools into one system, MindForge enhances team productivity, streamlines workflows, and improves overall project coordination.

    Technologies Used: MongoDB, Express.js, React.js, Node.js (MERN Stack)
    GitHub Repository: github.com/mindforge

  • Voyage Diaries – Travel Blog Website

    Voyage Diaries is a comprehensive online platform designed to foster a vibrant community of travelers. The platform’s core functionalities include writing and uploading travel blogs, content creation tools, personalized bucket lists, community forums, an AI chatbot for user assistance, a destination recommendation system, and a rewards system to incentivize engagement.

    This platform offers a unique blend of social networking features, destination management tools, and interactive community engagement, empowering users to document their adventures, discover new destinations, and connect with a global network of like-minded individuals.

    Technologies Used: Python, Django/Flask, HTML, CSS, JavaScript, Bootstrap
    GitHub Repository: github.com/VoyagDiaries
